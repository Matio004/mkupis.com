# DeadPixelGame
**DeadPixelGame** is a project for scientific club. The goal is to develop a game based on raycasting.

<img width="1278" height="750" alt="image" src="https://github.com/user-attachments/assets/3ed787aa-e073-4e3a-af18-34dafb92ec0f" />

## Features
1. Hidden rooms
2. Sprites
3. Weapons

## Built with
* **Language**: Python
* **Frameworks and Libraries**: pygame, opencv, taichi

## Getting started
1. ```git clone https://github.com/Matio004/DeadPixelGame.git```
2. ```cd DeadPixelGame/src```
3. ```uv run python main.py```
